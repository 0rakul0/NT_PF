# Linha de base para comparação

Esta pasta preserva os artefatos da rodada concluída antes da configuração mais conservadora.

- Amostra: 30% da base.
- Lote: 500 documentos.
- Limiar de confiança WNN: 0,50.
- Estratégia textual: corpo como evidência primária de crime e *modus operandi*, com tags apenas como pista auxiliar.

A próxima rodada deve usar lote de 100 documentos e limiar WNN de 0,70. Os arquivos copiados desta pasta não devem ser sobrescritos; eles constituem a linha de base para comparar cobertura WNN, encaminhamentos à LLM, custo de tokens e resultados por lote.
